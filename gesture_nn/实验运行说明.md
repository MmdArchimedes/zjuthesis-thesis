## 面向非专业人员的两步操作说明

## 实验一：手势识别 DBEW-NN 对比实验

**这个实验对比三种手势识别方法：几何规则（手写判据）、CNN-only（纯CNN）、CNN+Attention（本文方案）。**

### 第一步：确认环境就绪

打开终端（Win+R → 输入 `cmd` → 回车），逐条执行：

```bash
# 确认 Python 版本 ≥ 3.9
python --version

# 确认依赖包已安装
python -c "import torch; import numpy; import scipy; print('环境OK')"
```

如果报错 `ModuleNotFoundError`，先安装依赖：

```bash
pip install torch numpy scipy matplotlib --quiet
```

### 第二步：进入实验目录

```bash
cd C:\Users\12078\Documents\thesis\gesture_nn
```

### 第三步：运行完整管线

```bash
python main.py --device cpu
```

**这行命令会自动完成以下所有步骤：**

| 步骤 | 内容 | 预计耗时 |
|------|------|----------|
| ① 生成训练数据 | 合成 10人×3时段×7类手势 ≈ 25万帧 | 1-2 分钟 |
| ② 训练完整模型 | CNN+Attention（57K 参数） | 5-15 分钟 |
| ③ 训练消融模型 | CNN-only（40K 参数） | 3-10 分钟 |
| ④ 运行三组实验 | 精度对比 + 鲁棒性 + 端侧性能 | 2-5 分钟 |

**总耗时约 15-30 分钟（取决于 CPU 性能）。**

## 实验二：TSTQ--Fusion 多模态融合实验

**这个实验模拟用户在 AR 眼镜上同时使用手势+语音+射线三种交互，测试融合仲裁机制的准确性。**

这个实验**不需要神经网络，不需要 GPU**，纯数学模拟，秒级运行。

### 运行命令

```bash
cd C:\Users\12078\Documents\thesis\gesture_nn
python fusion_experiment.py
```

### 参数说明

实验模拟了论文中描述的真实场景参数：
- **6 名参与者**，每人等效约 **15 分钟** 操作
- 平均每 **3 秒** 产生一个交互事件
- 手势占 45%、语音 30%、射线 25%（匹配实际使用比例）
- 时间窗 ΔT = **500ms**（论文默认值）
- 低置信度过滤阈值与论文一致

如果需要固定结果（可复现）：

```bash
python fusion_experiment.py --seed 42
```

| 实验输出 | 论文位置 | 对应表格 |

### 将数据写入论文

1. 运行 `python main.py --device cpu` 得到实验一数据
2. 运行 `python fusion_experiment.py` 得到实验二数据
3. 复制 `experiment_results_v2/tables/*.tex` 中的表格到论文 content.tex 对应位置
4. 复制 `fusion_results/fusion_table.tex` 到论文 content.tex 对应位置
5. 重新编译论文 PDF

## 常见问题

### Q: 报错 `No module named 'torch'`
```bash
pip install torch --quiet
```

### Q: 报错 `No module named 'scipy'`
```bash
pip install scipy --quiet
```

### Q: CPU 训练太慢怎么办
CPU 训练 15-30 分钟是正常的。如果有 NVIDIA 显卡且已安装 CUDA 版 PyTorch，可以去掉 `--device cpu` 加速。

### Q: 想重新生成全套图表（混淆矩阵、t-SNE、注意力热力图等）
```bash
python experiments_v2.py --device cpu --data_dir data --model_path checkpoints/full/best_model.pt --output_dir experiment_results_v2
```
这会生成 `experiment_results_v2/figures/` 下的所有 PDF 图表和 `experiment_results_v2/tables/` 下的所有 LaTeX 表格。
